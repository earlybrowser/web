DISTRIBUTION

Download & Install

Zero dependencies. Completely free and open-source.

Homebrew Cask

Install and keep Early updated via the official tap:

brew tap earlybrowser/tap && brew install --cask early-browser

Build from Source

Compile directly with Swift 6 and Xcode:

git clone https://github.com/earlybrowser/early-browser.git && cd early-browser && xcodebuild -project Early.xcodeproj -scheme Early -configuration Debug build

ARCHITECTURE

Native macOS Engineering

Built with Swift 6, AppKit, SwiftUI, and WebKit.

Pure Native WebKit Stack

Early uses native NSWindow hierarchies and direct WKWebView management. By eliminating Chromium and Electron, memory consumption drops by 80% and startup latency is virtually eliminated.

Resource Comparison

Metric Early (Native WebKit) Chromium / Electron
Idle RAM (1 Tab) ~42 MB ~450 MB – 700 MB
Cold Launch < 0.2s ~1.5s – 3.0s
Process Isolation Swift 6 Actor Isolation Node.js IPC Bridge
Accessibility Native VoiceOver & Contrast Web emulation
